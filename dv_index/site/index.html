How bills are flagged

Source

The Legislature's official bulk data (downloads.leginfo.legislature.ca.gov). For each AB and SB bill, the tool reads the latest version's title, subject and Legislative Counsel's Digest.

Direct

The bill names domestic, intimate partner, dating or family violence, or cites a section of the Domestic Violence Prevention Act (Family Code §§6200–6409).

Indirect

The bill touches an impact area (housing, immigration, custody, firearms and so on) and uses victim or safety language. Some citations count on their own, such as Civil Code §1946.7, which lets victims end a lease.
